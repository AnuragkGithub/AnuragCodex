# UPSK Notes App

This repo is the first project for the UPSK bootcamp path.

## Goal

Build a simple notes app while learning system design fundamentals and creating public evidence for the profile.

## Project structure

- `index.html` - app entry point
- `styles.css` - visual design
- `app.js` - note behavior and local storage
- `docs/bootcamp/` - session notes and curriculum progress
- `docs/proof/` - public-proof drafts and evidence logs
- `backend/` - future backend work for later sessions

## Current session

Session 1: System Design Fundamentals

Focus:
- define the user goal
- define the data model
- identify future growth and failure cases
- capture proof of decisions

## Run it

Open `index.html` in a browser.
