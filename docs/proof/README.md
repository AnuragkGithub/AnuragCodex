# Public Proof Profile

This folder collects evidence for the UPSK public hiring profile.

## How to use it

- Add one file per session or project milestone.
- Record what you built, what you changed, what you verified, and what you decided.
- Keep the evidence short, specific, and factual.

## Suggested format

1. Session or module name
2. Problem or goal
3. Decision and tradeoff
4. What was verified
5. Short evidence note
